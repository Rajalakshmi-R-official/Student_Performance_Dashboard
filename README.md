# Student Performance Dashboard

## Overview
This project is a **Power BI dashboard** that analyzes student academic performance across multiple dimensions such as class, gender, state, school type, family income, internet access, and tuition classes.  
It provides insights into attendance, study hours, exam scores, and pass/fail rates, helping educators and institutions identify trends and areas for improvement.

---

## Key Features
- **Summary Metrics**
  - Total Students: 1000
  - Pass Percentage: 98.20%
  - Average Score: 69.24
  - Average Attendance: 79.70%
  - Average Study Hours: 4.48 hours/day

- **Visual Insights**
  - Average Score by Class (10, 11, 12)
  - Performance Category Distribution (Excellent, Good, Average, Poor)
  - Average Score by Gender
  - Exam Score by School Type (Private vs Government)
  - State-wise Score & Pass Percentage comparison
  - Internet Access Distribution
  - Family Income vs Performance Category
  - Tuition Classes vs Performance Category
  - Map visualization of student performance across Indian states

## How to Use
1. **Download the `.pbix` file** from this repository.
2. Open it using **Power BI Desktop** (free to install from Microsoft).
3. Interact with filters (Class, Gender, State, School Type, Result) to explore insights.

---

## Data Source
- The dataset used in this project was obtained from **[Kaggle] https://www.kaggle.com/**.  
- It contains structured academic records of students, including demographics, attendance, study hours, exam scores, and performance categories.
